# Fishbone Diagram Builder (مخطط هيكل السمكة)

هذا تطبيق ويب تفاعلي بسيط يساعدك على رسم مخطط هيكل السمكة (Ishikawa Diagram) لتحليل الأسباب الجذرية للمشكلات.

## المميزات
- إضافة وتعديل رأس السمكة (المشكلة الأساسية).
- إضافة، تعديل، أو حذف الأسباب الرئيسية (العظام الكبيرة).
- إضافة تفاصيل (أسباب فرعية) لكل عظمة.
- **تصدير كصورة**: بضغطة زر يمكنك حفظ المخطط كصورة PNG بجودة عالية.
- يدعم اللغة العربية بالكامل (RTL).

## كيف تستخدم التطبيق؟
1. قم برفع ملف `index.html` إلى أي مستودع (Repository) على GitHub.
2. ادخل على إعدادات المستودع (Settings) ثم **Pages**.
3. فعل خدمة **GitHub Pages** واصبر ثواني، سيظهر لك رابط، افتحه ومبروك عليك التطبيق شغال.

## المكونات التقنية
- تم استخدام HTML5 و CSS3 لتصميم الواجهة.
- تم استخدام JavaScript للتحكم التفاعلي.
- تم استخدام مكتبة `html2canvas` لمعالجة تصدير الصورة.
